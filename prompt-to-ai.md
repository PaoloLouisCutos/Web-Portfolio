Prompt-to-Prompt Plan for This Portfolio Project
Prompt 1: Project Setup
Use this prompt to generate the initial portfolio structure:

“Create a modern personal portfolio website for Paolo Louis Cutos, born December 27, 2002. The website should include a navigation bar, hero section, about me section, projects section, hobbies section, contact section, and footer. Use HTML, CSS, and JavaScript only. The page should have a clean, premium dark theme with a professional layout. Make it fully responsive for desktop and mobile screens. Use semantic HTML and modern styling.”

Prompt 2: Dynamic Content Requirement
Use this prompt to enforce the loop-based structure:

“Build the portfolio so that repeated content is generated dynamically using JavaScript arrays and forEach loops instead of hardcoding repeated HTML elements. Create arrays for navigation items, projects, hobbies, and contact links. Use JavaScript to populate the page sections into empty containers in the HTML. For example, have a section with a div id='projects-container' and then generate each project card using a loop.”

Prompt 3: Content Section Prompt
Use this prompt to define the actual content:

“Write content for the portfolio website with the following sections:

Navigation: Home, About, Projects, Hobbies, Contact
Hero: a short introduction and call-to-action buttons
About Me: a brief professional bio
Projects: 3 project cards with titles, tags, descriptions, and bullet features
Hobbies: 3 hobby cards with titles, tags, and descriptions
Contact: email, LinkedIn, and GitHub buttons
Footer: copyright with the name Paolo Louis Cutos”
Prompt 4: Styling Prompt
Use this prompt to make it visually professional:

“Style the portfolio with a modern dark background, subtle glassmorphism or card-based layout, accent blue highlights, readable typography, smooth hover effects, and a consistent spacing system. Ensure all cards and sections align neatly and respond well on smaller screens.”

Prompt 5: Final Polish Prompt
Use this prompt for the finishing pass:

“Review the generated portfolio and refine it to look polished and professional. Ensure the code is clean, consistent, and easy to understand. Keep the JavaScript loop-based pattern intact. Remove unnecessary complexity and make sure all links and sections work properly.”
